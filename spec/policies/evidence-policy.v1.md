# Evidence Policy v1

- Ask the user about user-owned preferences; do not use web evidence as a substitute.
- Use bounded primary or official sources for external material facts when the result can change the contract or plan.
- Every evidence record states claim, source reference, publication/update date when available, retrieval scope, exact applicability, freshness, confidence limits, and disposition.
- Tag material support as `directly_supported`, `contradicts_premise`, `near_match_only`, or `insufficient`.
- Benchmarks and SOTA are comparison evidence, not user requirements. They enter the contract only after user disposition.
- Contradictory or superseding evidence never deletes history; it appends a correction and invalidates dependent contract fields or closure as required.
- Deterministic tests never access the network. Live research behavior remains a separately validated host capability.
